Parte 1 • Entendendo as ferramentas

O que são GitHub e GitHub Pages?

📁

GitHub

É uma plataforma para guardar arquivos de projetos, acompanhar alterações no código e trabalhar em equipe.

Exemplo: você salva o código do seu site de uma loja no GitHub.
🌍

GitHub Pages

É um recurso gratuito para publicar páginas estáticas feitas com HTML, CSS e JavaScript.

Exemplo: outras pessoas abrem seu site por um link na internet.
🔧

Git

É um sistema que registra as versões dos arquivos. Git e GitHub são relacionados, mas não são a mesma coisa.

Exemplo: você consegue acompanhar o que foi alterado em um projeto.
Parte 2 • Palavras importantes

Termos que você vai encontrar

📦 Repositório

É como uma pasta do projeto dentro do GitHub.

📄 index.html

Arquivo principal da página inicial. O GitHub Pages normalmente o utiliza para abrir seu site.

🌿 Branch

Uma linha de desenvolvimento do projeto, como a main.

✅ Commit

Registro de uma alteração que você salvou nos arquivos do projeto.

🎨 CSS

Linguagem usada para mudar cores, tamanhos, espaçamento e aparência.

⚡ JavaScript

Linguagem que permite interações, como botões, menus e perguntas.

Parte 3 • Tutorial prático

Como criar e publicar seu site

Siga os passos na ordem. Os textos dos botões do GitHub podem aparecer em inglês mesmo quando o navegador está traduzido.

1

Entre no GitHub

Acesse github.com e entre na sua conta.

2

Crie um repositório

Clique em New repository (Novo repositório), escolha um nome, marque Public (Público) e clique em Create repository.

3

Envie o arquivo correto

Clique em Add file → Upload files (Adicionar arquivo → Enviar arquivos) e envie index.html sem colocar dentro de ZIP. Clique em Commit changes.

4

Abra as configurações

No repositório, clique em Settings (Configurações) e depois em Pages (Páginas).

5

Ative o GitHub Pages

Em Build and deployment → Source, escolha Deploy from a branch. Selecione main e /(root) e clique em Save.

Exemplo ilustrativo • Settings / Pages
Build and deployment

Source: Deploy from a branch

6

Abra e compartilhe seu link

Depois da publicação, o endereço costuma seguir este padrão:

https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/

Copie o endereço e envie pelo WhatsApp, redes sociais ou para o professor.

Parte 4 • Tecnologia do site

Como um site é construído?

HTML = Estrutura 🧱

Coloca título, parágrafos, imagens e links.

CSS = Aparência 🎨

Personaliza o visual com estilos e cores.

JavaScript = Interação 🎮

Faz um botão responder quando você clica.

Exemplo de código HTML simples

<!DOCTYPE html>
<html lang="pt-BR">
  <head>
    <meta charset="UTF-8">
    <title>Meu Primeiro Site</title>
  </head>
  <body>
    <h1>Olá, mundo!</h1>
    <p>Meu site está no GitHub Pages.</p>
  </body>
</html>

Parte 7 • Solução de problemas

O que fazer se o site der erro?

❌ Erro 404

Confira se o repositório é o correto, se o arquivo se chama exatamente index.html e se está na pasta publicada.

📦 Só enviei um ZIP

Extraia os arquivos no computador e envie o index.html diretamente para o repositório.

⏳ Ainda não abriu

A publicação pode demorar alguns minutos. Verifique o status em Settings → Pages e tente novamente.

🖼️ Imagens não aparecem

Verifique se os nomes dos arquivos e os caminhos usados no HTML estão iguais, incluindo letras maiúsculas e minúsculas.

Parte 9 • Perguntas frequentes

Dúvidas comuns

O GitHub Pages é gratuito?

Sim. Você pode publicar sites estáticos gratuitamente usando repositórios públicos, respeitando os limites e regras do serviço.

Preciso pagar para ter um link?

Não. O GitHub Pages disponibiliza um endereço no domínio github.io sem custo.

Posso usar imagens?

Sim. Envie as imagens para o repositório e coloque seus caminhos corretamente no HTML.

Posso atualizar o site depois de publicar?

Sim. Altere os arquivos e salve as mudanças no repositório. O Pages poderá publicar a nova versão automaticamente.

O GitHub Pages aceita PHP ou banco de dados no servidor?

Não diretamente. O GitHub Pages hospeda conteúdo estático, como HTML, CSS e JavaScript.
